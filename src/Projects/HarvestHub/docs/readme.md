# HarvestHub Site (v1)

A diverse agricultural supermarket that provides livestock, poultry, frozen foods, produce and staples. Retail and bulk supply.

# Features: 
- Category slider
- Bulk Supply For Businesses
- Products can be added to cart
- Allowance of product enquiries
- Users can send enquiries about products
- Communication through whatsApp or E-mail
- Quantity counter for product to be bought
- Customer Service through whatsApp or E-mail
- Order summary giving information about the products about to be bought
- Products of specific categories can be viewed via the category section
- Shop where all products are displayed, searched through, filtered, and sorted
- Products of relation are displayed in the pdp of others (via category matching)
- Checkout form requesting information that allows HarvestHub to deliver user's order
- Product details are revealed in each product's display page (via button or img on product card)
